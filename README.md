# Property-Optimizer
Built an interactive web app to compute the optimal property mix for maximizing earnings on Mars Land based on available time units.

DATA PIPELINE: Input time units → Dynamic Programming → Backtracking → Optimal Building Combination → Streamlit Visualization

FEATURES: Calculates maximum earnings with the best combination of Theatres, Pubs, and Commercial Parks. Interactive Streamlit interface shows building counts, earnings, and explanation. Handles all time-unit scenarios.

TECH STACK: Python | Streamlit | Dynamic Programming | Backtracking | Interactive UI

IMPACT: Converts user input into an optimal development plan → visualizes results → enables strategic decision-making for maximum profit. Perfect demo of algorithmic optimization in real-time.
